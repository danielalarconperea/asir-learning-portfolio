Recomendacion:

1. Revisar en GitHub que `asir-learning-portfolio` se ve bien.
2. Fijar `asir-learning-portfolio` en el perfil.

4. Cuando este todo comprobado, archivarlos en GitHub para que queden como historico.

Archivarlos es mejor que borrarlos: no pierdes nada, pero dejan de parecer repos activos.
