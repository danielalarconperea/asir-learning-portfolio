# PROYECTO FINAL: "JavaScript Wallet" 💰

> **Tu Misión:** Construir una aplicación web para controlar tus gastos personales.

---

## 🚀 La Idea

Una aplicación simple pero poderosa que te permite registrar cuánto ganas y cuánto gastas, calculando tu saldo actual en tiempo real. Olvídate de las hojas de cálculo aburridas.

**Slogan:** *"Tu dinero, bajo tu control."*

## ⭐ ¿Por qué este proyecto?

Este proyecto es perfecto porque combina **Lógica de Datos** (cuánto dinero tengo) con **Interacción Visual** (ver la lista de gastos). Cubre el 100% del temario de 1ASIR/2ASIR:

1. **Variables**: Para guardar el saldo total.
2. **Arrays y Objetos**: Para guardar la lista de transacciones (ej: `{ concepto: "Pizza", cantidad: -15 }`).
3. **Funciones**: `agregarGasto()`, `calcularSaldo()`, `borrarTransaccion()`.
4. **DOM (Si lo haces web)**: Pintar la lista de gastos en el HTML.
5. **LocalStorage (Bonus)**: Para que los datos no se borren al recargar la página.

## 🛠️ Características (Features)

### Fase 1: MVP (Producto Mínimo Viable)

- [ ] Un formulario para añadir un ingreso o gasto (Concepto y Cantidad).
- [ ] Una lista visual que muestra el historial.
- [ ] Un indicador grande del **Saldo Total**.
- [ ] Colores dinámicos: Verde si el saldo es positivo, Rojo si estás en números rojos.

### Fase 2: Nivel Experto (Para nota)

- [ ] **Filtros**: Ver solo gastos o solo ingresos.
- [ ] **Persistencia**: Usar `localStorage` para guardar los datos en el navegador.
- [ ] **Gráficos**: Usar una librería simple (o CSS) para ver gastos por categoría.
